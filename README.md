# Awesome-Connected-Worker-Platform

# 顶级互联工人平台生态系统

**精选 SaaS 产品与开源 GitHub 项目列表**
*聚焦数字作业指导书、前线操作赋能、知识捕获与合规执行*
**最后更新：2026 年 9 月**

本仓库追踪**互联工人平台**领域的知名 **SaaS 平台**与**开源项目**。这些工具帮助制造、能源、建筑等行业的前线团队以数字化方式执行标准作业程序（SOP）、捕获一线知识、确保合规，并赋能无桌面的操作人员。

**示例**包括 Augmentir、Parsable、Poka、MaintainX、Tulip、Proceedix、Dozuki、SwipeGuide、REWO 和 Intoware（该领域的领先者）。

**开源重点**：互联工人领域拥有**活跃的开源生态**，主要集中在两个方向：**开源 CMMS/EAM 平台**（如 Grash、openMAINT）提供维护工单和资产管理，以及**文档/知识管理工具**（如 Outline、Docmost）用于捕获和共享作业指导。此外，**Dozuki** 等商业平台虽然本身不开源，但其内容管理理念与开源文档工具高度契合。本列表重点收录**可自托管的 CMMS** 和**知识管理系统**。

欢迎贡献！提交 PR 以添加/更新条目。保持描述事实性，并链接到官方网站。

## SaaS/托管平台

- **[Augmentir](https://www.augmentir.ai/)**  
  AI 驱动的互联工人平台，专注于数字作业指导书和技能管理。与 ERP、MES、CMMS、EH&S、LMS、QMS 系统集成，支持 5S 审计、Gemba 巡视、质量管理、安全管理和自主维护等用例 。平台将 AI 与数字工作流和远程协作功能结合，帮助工业前线团队提升运营效率 。

- **[Parsable](https://www.parsable.com/)**  
  面向工业团队的移动协作与工作流平台。提供富媒体 SOP、数字数据采集、应用内消息和离线执行能力。支持无代码模板构建，可与现有系统集成，提供分析和审计报告 。Microsoft Teams 连接器支持前线与后办公室的协作 。

- **[Poka](https://www.poka.io/)**  
  工业 AI 驱动的互联工作平台，被 3,000+ 站点、100 万+ 用户使用 。核心能力包括验证过的程序、实时技能可见性和运营智能。帮助 Tetra Pak 等客户消除因人员技能不足造成的生产损失 。

- **[MaintainX](https://www.getmaintainx.com/)**  
  移动优先的工作流管理平台，专为无桌面员工设计。提供 CMMS 功能，支持工单管理、安全清单、质量检查，创建数字审计追踪 。帮助 Subway 加盟商管理 7 个地点的 140 台设备 。

- **[Tulip](https://tulip.co/)**  
  无代码互联工人和制造应用平台。支持构建富媒体、多语言的工作流应用，连接机器、设备和传感器，与 ERP、MES、PLM 集成 。2025 年 Litmus Automation ISV 合作伙伴奖得主 。

- **[Proceedix](https://www.symphonyai.com/)**  
  SymphonyAI 的互联工人平台。将工作指令、检查和培训统一到一个 AI 驱动环境中。AI Copilot 提供基于当前工作流的精确指导 。支持 GxP 合规签名（21 CFR Part 11）。

- **[Dozuki](https://www.dozuki.com/)**  
  自 2011 年以来的互联工人平台先驱。2025 年实现 45% 企业客户增长，98% CSAT 评分 。CreatorPro AI 使文档数字化增长 724%。Knowledge Management、Operational Workflows 和 Worker Collaboration 模块构成核心能力 。

- **[SwipeGuide](https://www.swipeguide.com/)**  
  荷兰数字作业指导书和 SOP 平台，2015 年成立。客户包括 Heineken、ABB、Orkla 。2024 年被 L2L 收购，加入互联劳动力生态系统 。

- **[REWO](https://www.rewo.io/)**  
  斯洛文尼亚 Viar d.o.o. 开发的视觉数字化平台。用于捕获、可视化和沟通知识，支持作业指导、培训入职、现场支持和复杂小批量装配 。在航空航天、汽车、食品等行业有应用 。

- **[Intoware (WorkfloPlus)](https://www.intoware.com/)**  
  互联工人平台，提供 WorkfloPlus 数字工作流解决方案。2025 年与 RealWear 宣布战略合作，将平台与工业可穿戴设备集成 。

## 开源 GitHub 项目

### CMMS / 维护管理

- **[Grash](https://github.com/grash-io/grash)**  
  免费开源 CMMS 和 EAM 平台，GPL-3.0 许可。提供工单管理、预防性维护、资产管理和备件库存功能。支持 Docker 部署，活跃开发中。

- **[openMAINT](https://github.com/tecnoteca/openmaint)**  
  源自 CMDBuild 的开源维护系统，适用于房地产、物流和工业场景。功能包括工单管理、预防性维护、资产登记、条码/QR 码打印和 GIS 地理定位。AGPL 许可 。

- **[CMMS (MaintSmart 替代)](https://github.com/topics/cmms)**  
  GitHub `cmms` 主题下有多个活跃开源项目，包括 **Grash**、**openMAINT** 和 **CMMS (arunlodhi)** 等，提供不同复杂度的维护管理能力。

- **[Open Source CMMS (SuperCMMS)](https://github.com/SuperCMMS/Open-Source-CMMS)**  
  免费开源 CMMS 后端代码库。提供资产管理、工单、预防性维护、预测性维护、检查表、QR 码和库存管理。目前快速开发中，尚未生产就绪。

- **[WCC CMMS](https://github.com/devdave-online/WCC_CMMS)**  
  免费无限席位 CMMS，支持 34 种语言、离线 Android 伴生应用和 AI 代理支持。功能包括完整工单生命周期、预防性维护、资产登记、QR/DataMatrix 标签打印、库存台账和可靠性 KPI（MTTR、MTBF）。Apache License 2.0 + Commons Clause。

### 知识管理与文档

- **[Outline](https://github.com/outline/outline)**  
  快速、协作的知识库，具有类似 Notion 的编辑器。支持实时协作、嵌套集合、Slack 集成和 AI 搜索。BSL 1.1 许可，~38.8k stars。可用于捕获和共享 SOP 和作业指导。

- **[Docmost](https://github.com/docmost/docmost)**  
  开源 Confluence/Notion 替代，用于团队 Wiki。支持实时协作、空间、细粒度权限和原生图表。AGPL-3.0 许可，~21k stars。

- **[BookStack](https://github.com/BookStackApp/BookStack)**  
  结构化文档平台，按书架 → 书 → 章节 → 页面组织。WYSIWYG 和 Markdown 编辑器，基于角色的权限和全文搜索。MIT 许可，~16k stars。适合非技术团队管理作业指导。

- **[WeKnora (腾讯)](https://github.com/Tencent/WeKnora)**  
  LLM 驱动的企业知识框架。将原始文档转化为可查询的 RAG、自主推理代理和自维护 Wiki。Wiki 模式自动生成结构化、互链的 Markdown 页面。MIT 许可。

### 其他强开源选项

- **CMMS/EAM**：**Grash**（GPL-3.0，活跃）、**openMAINT**（AGPL，GIS 集成）、**WCC CMMS**（无限席位，离线支持）。
- **知识管理**：**Outline**（BSL 1.1，Notion-like）、**Docmost**（AGPL-3.0，Confluence 替代）、**BookStack**（MIT，结构化文档）。
- **AI 增强**：**WeKnora**（LLM 驱动的 RAG 和 Wiki 生成）。

**构建自定义系统的框架**：结合 **Grash** 或 **openMAINT** 用于工单和资产管理，**BookStack** 或 **Outline** 用于作业指导书和知识库，**Docmost** 用于团队协作空间。添加 **PostgreSQL** 用于持久化，**Docker** 用于部署。

## 免责声明

- 这是一个**社区精选**列表——并非详尽无遗，也不构成认可。
- 互联工人平台处理敏感的运营和员工数据；确保符合相关数据保护法规和行业合规要求。
- **开源现实**：互联工人平台的开源生态在 **CMMS/维护管理**（Grash、openMAINT、WCC CMMS）和 **知识管理**（Outline、BookStack）层面已经成熟可用，但**完整的互联工人体验**（移动端离线执行、AI 指导、实时协作、技能矩阵、GxP 合规签名）需要将多个开源工具集成或采用商业平台。Augmentir、Parsable、Poka 等商业平台提供更完整的端到端解决方案 。
